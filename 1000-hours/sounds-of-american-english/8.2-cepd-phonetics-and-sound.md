# 8.2. Lấy phiên âm và âm thanh CEPD

Trên GitHub có một repository mã nguồn mở được nguyên tác dẫn, cung cấp cơ sở dữ liệu JSON của Cambridge English Pronouncing Dictionary:

> https://github.com/zelic91/camdict

Theo hướng dẫn gốc, tải [cam_dict.refined.json](https://github.com/zelic91/camdict/raw/main/cam_dict.refined.json) từ repository đó và lưu vào một vị trí trên máy.

Tác giả đã viết một workflow Alfred sử dụng *python3* ở đường dẫn `/usr/bin/python3` trên macOS của mình. Workflow khởi chạy script Python bằng từ khóa để tra phiên âm một từ, thậm chí cả câu, trong Cambridge English Pronouncing Dictionary (CEPD). Ghi chú biên tập: cần xác nhận Python thực sự có ở đường dẫn này trên máy của bạn, không mặc định mọi bản macOS đều cung cấp sẵn cùng môi trường.

> [CEPD-phonetic-transcription.alfredworkflow](https://1000h.org/alfred-workflows/CEPD-phonetic-transcription.alfredworkflow)

Sau khi tải tệp, nhập vào Alfred theo hướng dẫn gốc.

Trước khi dùng, cần chú ý:

> * Sửa đường dẫn tới `cam_dict.refined.json` trong từng script Python cho đúng vị trí lưu trên máy.

Các từ khóa khởi chạy của workflow:

> * `cams`: tra phiên âm giọng Mỹ.
> * `camk`: tra phiên âm giọng Anh.
> * `camsd`: mở URL bản nghe người thật CEPD giọng Mỹ trong trình duyệt.
> * `camkd`: mở URL bản nghe người thật CEPD giọng Anh trong trình duyệt.
> * `camw`: mở trang tra CEPD.
> * `ipa`: trả phiên âm từ kho CMU của Carnegie Mellon University.

Dưới đây là script Python trong workflow tra phiên âm với từ khóa `cams`:

```python
#
# NOTE: Python 2 is deprecated in macOS, and has been removed from macOS 12.3+
#
import sys
import json

# Load the JSON database from a local file.
# Adapt this section if the data is in memory or another format.
def load_json_database(file_path):
    records = []
    with open(file_path, 'r') as file:
        for line in file:
            try:
                record = json.loads(line)
                records.append(record)
            except json.JSONDecodeError as e:
                print(f"Error parsing JSON: {e}")
    return records

# Search for the word in the JSON database.
def search_in_json_database(database, search_word, region):
    for record in database:
        # Check whether the word field matches.
        if record.get('word') == search_word:
            # Read American pronunciation information for the matching entry.
            pos_items = record.get('pos_items', [])
            for pos_item in pos_items:
                pronunciations = pos_item.get('pronunciations', [])
                for pronunciation in pronunciations:
                    if pronunciation.get('region') == region:
                        # Return the matching American pronunciation.
                        return {
                            'pronunciation': pronunciation.get('pronunciation'),
                            'audio': pronunciation.get('audio')
                        }
    # Return 'not exist' when no matching word is found.
    return 'not exist'

# Path to cam_dict.refined.json.
json_db_file_path = '/Users/joker/github/camdict/cam_dict.refined.json'

# Word to look up.
search_word = sys.argv[1]

region = "us"

json_database = load_json_database(json_db_file_path)

# replace punctuations in text with space
punctuations = ",.?!;"
for p in punctuations:
    search_word = search_word.replace(p, " ")
words = [word for word in search_word.split() if word.strip() != '']

phonetics = []

for w in words:
  # Look up the word and collect the result.
  w = w.strip().lower()

  if w[-1] in punctuations:
    w = w.rstrip(",.?!;")
  result = search_in_json_database(json_database, w, region)

  if result == 'not exist':
    phonetics.append(w+"*")
  else:
    phonetics.append(result['pronunciation'])

returnvalue = ''
for p in phonetics:
  returnvalue += p + ' '

sys.stdout.write(returnvalue.strip())
```
