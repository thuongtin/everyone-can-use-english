# Nguồn kiểm chứng phương án thay Enjoy API

Ngày đọc: 08/09/2026. Các nguồn dưới đây là tài liệu hoặc repository của bên cung cấp. Chỉ dùng để xác nhận contract/capability được công bố, không phải bằng chứng đã chạy inference trên máy này. Kết luận lựa chọn và kế hoạch migration là đánh giá kỹ thuật của báo cáo.

## Những lần đọc không đủ bằng chứng

- `docs.speechace.com` không trả được nội dung cho công cụ trích xuất. Đã dùng repository chính chủ S17 để xác nhận loại capability, không suy diễn schema chi tiết hay giá từ trang rỗng.
- URL cũ `docs.anthropic.com/en/api/messages` và trang Google Cloud word-level timestamps trả lỗi qua công cụ đọc. Không dùng chúng làm bằng chứng trong ma trận cuối; không ảnh hưởng khuyến nghị ACP dựa trên code hiện có.
- OpenAI API reference HTML từng trả Internal Error khi tìm chuỗi. Bản Markdown chính chủ đọc thành công, xác nhận mô tả generic chưa giải quyết khác biệt với guide S04.
- Trang giá mô tả sản phẩm mới hơn một số sample trong tài liệu. Tên model trong sample không phải bằng chứng đó là model mới nhất. Báo cáo không xếp hạng chất lượng từ lời quảng bá của nhà cung cấp.
